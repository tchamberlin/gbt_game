## Overview
A client-side TypeScript game using Bun where players control the Green Bank Telescope to observe astronomical sources while avoiding satellites.

## Tech Stack
- **Runtime**: Bun
- **Language**: TypeScript
- **Rendering**: HTML5 Canvas (pixel art aesthetic)
- **Audio**: Web Audio API
- **Build**: Bun bundler

## Project Structure

## Core Mechanics

### 1. GBT Telescope (`telescope.ts`)
- **Profile view**: Dish + feed arm on 8 wheels, fixed to ground
- **Single axis**: Elevation only (tilts up/down toward mouse)
- **Slew rate limit**: Max angular velocity ~30°/sec (tunable)
- **Two positions tracked**:
  - `commandedElevation`: Where mouse points (rendered as `+`)
  - `actualElevation`: Current position (rendered as circle beam)
- **Update logic**: `actualElevation` moves toward `commandedElevation` at slew rate

### 2. Observation Beam
- Small circle rendered at actual GBT pointing position
- Collision detection: Circle-circle (beam vs sources/satellites)
- Observation timer per source: Accumulates while beam overlaps

### 3. Science Sources (`sources.ts`)

| Pulsar  | Small  | 1.5s             | 100    | Blinks visually |

| Quasar  | Tiny   | 1.0s             | 250    | Faint, hard to track |
| Galaxy  | Large  | 4.0s             | 400    | Easy to hit |
| FRB     | Small  | 0.5s             | 1000   | Appears briefly (~2s total), then vanishes |

- Move slowly left-to-right across sky

- Move rapidly (5-10x source speed)
- Random trajectories across sky

- Visual: Blinking lights, distinct from sources

### 5. Progressive Difficulty
- Every 30 seconds:
  - Increase satellite spawn rate

- FRBs become slightly more frequent over time

### 6. Audio (`audio.ts`)
- **Observation tick**: Soft ping while observing a source
- **Source complete**: Satisfying chime when fully observed
- **Satellite hit**: Warning buzz

- **Runtime**: Bun
- **Language**: TypeScript
- **Rendering**: HTML5 Canvas (pixel art aesthetic)
- **Audio**: Web Audio API
- **Build**: Bun bundler

## Core Mechanics

### 1. GBT Telescope (`telescope.ts`)
- **Profile view**: Dish + feed arm on 8 wheels, fixed to ground
- **Single axis**: Elevation only (tilts up/down toward mouse)
- **Slew rate limit**: Max angular velocity ~30°/sec (tunable)
- **Two positions tracked**:
  - `commandedElevation`: Where mouse points (rendered as `+`)
  - `actualElevation`: Current position (rendered as circle beam)
- **Update logic**: `actualElevation` moves toward `commandedElevation` at slew rate

### 2. Observation Beam
- Small circle rendered at actual GBT pointing position
- Collision detection: Circle-circle (beam vs sources/satellites)
- Observation timer per source: Accumulates while beam overlaps

### 3. Science Sources (`sources.ts`)
| Type    | Size   | Observation Time | Points | Special |
|---------|--------|------------------|--------|---------|
| Pulsar  | Small  | 1.5s             | 100    | Blinks visually |
| Maser   | Medium | 2.0s             | 150    | Steady glow |
| Quasar  | Tiny   | 1.0s             | 250    | Faint, hard to track |
| Galaxy  | Large  | 4.0s             | 400    | Easy to hit |
| FRB     | Small  | 0.5s             | 1000   | Appears briefly (~2s total), then vanishes |

- Move slowly left-to-right across sky
- Spawn randomly at right edge, despawn at left

### 4. Satellites (`satellites.ts`)
- Move rapidly (5-10x source speed)
- Random trajectories across sky
- Observing for any duration = instant point loss (e.g., -50 per hit)
- Visual: Blinking lights, distinct from sources

### 5. Progressive Difficulty
- Every 30 seconds:
  - Increase satellite spawn rate
  - Slightly increase satellite speed
  - Slight increase in source speed
- FRBs become slightly more frequent over time

### 6. Audio (`audio.ts`)
- **Observation tick**: Soft ping while observing a source
- **Source complete**: Satisfying chime when fully observed
- **Satellite hit**: Warning buzz
- **FRB spawn**: Distinctive alert sound
- Use Web Audio API to generate tones (no asset files needed)

### 7. Rendering (`renderer.ts`, `sprites.ts`)
- Responsive canvas maintaining 16:9 aspect ratio
- Pixel-perfect rendering (disable anti-aliasing)
- Color palette: Dark sky (#0a0a1a), stars, green/white GBT
- **GBT sprite**: ~128px tall, detailed with visible truss work, feed arm, dish structure
- Other sprites scaled proportionally to GBT detail level
- Pixel art sprites defined as arrays of pixel data or drawn procedurally

// Canvas rendering and pixel art utilities

const ASPECT_RATIO = 16 / 9;
const BASE_WIDTH = 1280;
const BASE_HEIGHT = 720;

export class Renderer {
  canvas: HTMLCanvasElement;
  ctx: CanvasRenderingContext2D;
  width: number = BASE_WIDTH;
  height: number = BASE_HEIGHT;
  scale: number = 1;
  private stars: { x: number; y: number; brightness: number }[] = [];

  constructor(canvasId: string) {
    const canvas = document.getElementById(canvasId) as HTMLCanvasElement;
    if (!canvas) throw new Error(`Canvas ${canvasId} not found`);

    const ctx = canvas.getContext('2d');
    if (!ctx) throw new Error('Could not get 2D context');

    this.canvas = canvas;
    this.ctx = ctx;

    this.setupResponsiveCanvas();
    window.addEventListener('resize', () => this.setupResponsiveCanvas());

    this.generateStars();
  }

  private setupResponsiveCanvas(): void {
    const containerWidth = window.innerWidth;
    const containerHeight = window.innerHeight;

    let width = containerWidth;
    let height = containerWidth / ASPECT_RATIO;

    if (height > containerHeight) {
      height = containerHeight;
      width = containerHeight * ASPECT_RATIO;
    }

    this.scale = width / BASE_WIDTH;
    this.width = BASE_WIDTH;
    this.height = BASE_HEIGHT;

    this.canvas.width = BASE_WIDTH;
    this.canvas.height = BASE_HEIGHT;
    this.canvas.style.width = `${width}px`;
    this.canvas.style.height = `${height}px`;

    // Disable anti-aliasing for pixel art
    this.ctx.imageSmoothingEnabled = false;
  }

  private generateStars(): void {
    this.stars = [];
    for (let i = 0; i < 200; i++) {
      this.stars.push({
        x: Math.random() * BASE_WIDTH,
        y: Math.random() * (BASE_HEIGHT * 0.7), // stars only in upper portion
        brightness: 0.3 + Math.random() * 0.7,
      });
    }
  }

  clear(): void {
    // Dark sky gradient
    const gradient = this.ctx.createLinearGradient(0, 0, 0, this.height);
    gradient.addColorStop(0, '#0a0a1a');
    gradient.addColorStop(0.7, '#0f0f2a');
    gradient.addColorStop(1, '#1a1a2a');
    this.ctx.fillStyle = gradient;
    this.ctx.fillRect(0, 0, this.width, this.height);
  }

  drawStars(): void {
    for (const star of this.stars) {
      const alpha = star.brightness * (0.7 + 0.3 * Math.sin(Date.now() / 1000 + star.x));
      this.ctx.fillStyle = `rgba(255, 255, 255, ${alpha})`;
      this.ctx.fillRect(Math.floor(star.x), Math.floor(star.y), 2, 2);
    }
  }

  drawGround(): void {
    const groundY = this.height * 0.85;

    // Ground
    this.ctx.fillStyle = '#1a2a1a';
    this.ctx.fillRect(0, groundY, this.width, this.height - groundY);

    // Ground line
    this.ctx.fillStyle = '#2a3a2a';
    this.ctx.fillRect(0, groundY, this.width, 3);
  }

  // Pixel art helper - draw a filled rectangle
  drawPixelRect(x: number, y: number, w: number, h: number, color: string): void {
    this.ctx.fillStyle = color;
    this.ctx.fillRect(Math.floor(x), Math.floor(y), w, h);
  }

  // Draw a circle (for beam)
  drawCircle(x: number, y: number, radius: number, color: string, fill: boolean = true): void {
    this.ctx.beginPath();
    this.ctx.arc(Math.floor(x), Math.floor(y), radius, 0, Math.PI * 2);
    if (fill) {
      this.ctx.fillStyle = color;
      this.ctx.fill();
    } else {
      this.ctx.strokeStyle = color;
      this.ctx.lineWidth = 2;
      this.ctx.stroke();
    }
  }

  // Draw a plus sign (for commanded position)
  drawPlus(x: number, y: number, size: number, color: string): void {
    this.ctx.fillStyle = color;
    const halfSize = Math.floor(size / 2);
    const thickness = Math.max(2, Math.floor(size / 5));
    const halfThick = Math.floor(thickness / 2);

    // Horizontal bar
    this.ctx.fillRect(
      Math.floor(x) - halfSize,
      Math.floor(y) - halfThick,
      size,
      thickness
    );
    // Vertical bar
    this.ctx.fillRect(
      Math.floor(x) - halfThick,
      Math.floor(y) - halfSize,
      thickness,
      size
    );
  }

  // Draw text with pixel font styling
  drawText(
    text: string,
    x: number,
    y: number,
    color: string,
    size: number = 16,
    align: CanvasTextAlign = 'left'
  ): void {
    this.ctx.fillStyle = color;
    this.ctx.font = `${size}px monospace`;
    this.ctx.textAlign = align;
    this.ctx.textBaseline = 'top';
    this.ctx.fillText(text, Math.floor(x), Math.floor(y));
  }

  // Get mouse position relative to canvas (accounting for scale)
  getMousePosition(event: MouseEvent): { x: number; y: number } {
    const rect = this.canvas.getBoundingClientRect();
    return {
      x: (event.clientX - rect.left) / this.scale,
      y: (event.clientY - rect.top) / this.scale,
    };
  }

  getGroundY(): number {
    return this.height * 0.85;
  }
}

// Draw the GBT telescope at a given position and elevation angle
export function drawGBT(
  renderer: Renderer,
  x: number,
  groundY: number,
  elevationDegrees: number
): void {
  const ctx = renderer.ctx;

  // GBT dimensions (128px tall detailed version)
  const wheelRadius = 8;
  const wheelSpacing = 18;
  const wheelBaseY = groundY - wheelRadius;
  const baseWidth = 160;
  const baseHeight = 20;
  const towerHeight = 80;
  const dishSize = 100;

  // Draw wheels (8 wheels in pairs)
  for (let i = 0; i < 4; i++) {
    const wx = x - baseWidth / 2 + 20 + i * wheelSpacing * 2;
    drawWheel(ctx, wx, wheelBaseY, wheelRadius);
    drawWheel(ctx, wx + wheelSpacing, wheelBaseY, wheelRadius);
  }

  // Draw base platform
  ctx.fillStyle = COLORS.structure;
  ctx.fillRect(
    Math.floor(x - baseWidth / 2),
    Math.floor(wheelBaseY - wheelRadius - baseHeight),
    baseWidth,
    baseHeight
  );

  // Draw support tower/truss
  const towerBaseY = wheelBaseY - wheelRadius - baseHeight;
  const towerTopY = towerBaseY - towerHeight;

  drawTrusswork(ctx, x, towerBaseY, towerTopY, 40);

  // Calculate dish center position
  const pivotY = towerTopY + 10;

  // Save context for rotation
  ctx.save();
  ctx.translate(x, pivotY);

  // Convert elevation to canvas rotation (0° = horizontal, 90° = vertical up)

// GBT telescope model with slew rate mechanics

import type { TelescopeState, Point, BeamState } from './types.ts';
import type { Renderer } from './renderer.ts';
import { drawGBT } from './sprites.ts';

const MIN_ELEVATION = 5;   // degrees - can't point below horizon
const MAX_ELEVATION = 90;  // degrees - straight up
const MAX_SLEW_RATE = 30;  // degrees per second
const BEAM_RADIUS = 15;    // pixels

export class Telescope {
  state: TelescopeState;
  private renderer: Renderer;

  constructor(renderer: Renderer) {
    this.renderer = renderer;

    // Position GBT at left side of screen
    const groundY = renderer.getGroundY();

    this.state = {
      commandedElevation: 45,
      actualElevation: 45,
      maxSlewRate: MAX_SLEW_RATE,
      x: 150, // Fixed x position
      y: groundY,
    };
  }

  // Update commanded elevation based on mouse position
  setCommandedPosition(mousePos: Point): void {
    // Calculate angle from telescope position to mouse
    const dx = mousePos.x - this.state.x;
    const dy = this.state.y - mousePos.y; // Inverted because canvas y increases downward

    if (dx <= 0 && dy <= 0) {
      // Mouse is behind or below telescope, ignore
      return;
    }

    // Calculate elevation angle in degrees
    let elevation = Math.atan2(dy, Math.max(dx, 1)) * (180 / Math.PI);

    // Clamp to valid range
    elevation = Math.max(MIN_ELEVATION, Math.min(MAX_ELEVATION, elevation));

    this.state.commandedElevation = elevation;
  }

  // Update actual elevation with slew rate limiting
  update(deltaTime: number): void {
    const { commandedElevation, actualElevation, maxSlewRate } = this.state;

    const error = commandedElevation - actualElevation;

    if (Math.abs(error) < 0.1) {
      // Close enough, snap to target
      this.state.actualElevation = commandedElevation;
    } else {
      // Slew toward commanded position at max rate
      const maxChange = maxSlewRate * deltaTime;
      const change = Math.sign(error) * Math.min(Math.abs(error), maxChange);
      this.state.actualElevation += change;
    }
  }

  // Get beam position (where telescope is actually pointing)
  getBeamState(): BeamState {
    const { actualElevation, x, y } = this.state;

    // Calculate beam position far from telescope
    const beamDistance = this.renderer.width; // Extend to edge of screen
    const elevationRad = actualElevation * (Math.PI / 180);

    return {
      x: x + Math.cos(elevationRad) * beamDistance,
      y: y - Math.sin(elevationRad) * beamDistance,
      radius: BEAM_RADIUS,
    };
  }

  // Get commanded position in screen coordinates
  getCommandedPosition(): Point {
    const { commandedElevation, x, y } = this.state;
    const beamDistance = this.renderer.width;
    const elevationRad = commandedElevation * (Math.PI / 180);

    return {
      x: x + Math.cos(elevationRad) * beamDistance,
      y: y - Math.sin(elevationRad) * beamDistance,
    };
  }

  // Get a point along the actual beam path at a specific distance
  getBeamPointAtDistance(distance: number): Point {
    const { actualElevation, x, y } = this.state;
    const elevationRad = actualElevation * (Math.PI / 180);

    return {
      x: x + Math.cos(elevationRad) * distance,
      y: y - Math.sin(elevationRad) * distance,
    };
  }

  // Draw the telescope
  draw(): void {
    drawGBT(
      this.renderer,
      this.state.x,
      this.state.y,
      this.state.actualElevation
    );
  }

  // Draw the beam indicators
  drawBeamIndicators(): void {
    const beam = this.getBeamState();
    const commanded = this.getCommandedPosition();

    // Draw beam line (faint)
    this.renderer.ctx.strokeStyle = 'rgba(0, 255, 0, 0.15)';
    this.renderer.ctx.lineWidth = 2;
    this.renderer.ctx.setLineDash([10, 10]);
    this.renderer.ctx.beginPath();
    this.renderer.ctx.moveTo(this.state.x, this.state.y);
    this.renderer.ctx.lineTo(beam.x, beam.y);
    this.renderer.ctx.stroke();
    this.renderer.ctx.setLineDash([]);

    // Draw commanded position (+ sign) - where mouse is pointing
    // Only draw if visible on screen
    if (commanded.x < this.renderer.width && commanded.y > 0) {
      this.renderer.drawPlus(commanded.x, commanded.y, 20, 'rgba(255, 255, 0, 0.7)');
    }

    // Draw actual beam circle - where telescope is pointing
    // Draw along the beam path, not at the edge
    const beamDrawDistance = 400; // Draw beam at reasonable distance from telescope
    const beamDrawPos = this.getBeamPointAtDistance(beamDrawDistance);

    // Beam circle (hollow)
    this.renderer.drawCircle(beamDrawPos.x, beamDrawPos.y, BEAM_RADIUS, 'rgba(0, 255, 0, 0.8)', false);

    // Small filled center
    this.renderer.drawCircle(beamDrawPos.x, beamDrawPos.y, 3, 'rgba(0, 255, 0, 0.8)', true);
  }

  // Get beam position at the standard observation distance
  getObservationBeam(): BeamState {
    const beamPos = this.getBeamPointAtDistance(400);
    return {
      x: beamPos.x,
      y: beamPos.y,
      radius: BEAM_RADIUS,
    };
  }
}

import type { Source, SourceType, SourceConfig } from './types.ts';
import { SOURCE_CONFIGS } from './types.ts';
import type { Renderer } from './renderer.ts';

const SOURCE_TYPES: SourceType[] = ['pulsar', 'maser', 'quasar', 'galaxy'];

export class SourceManager {
  private sources: Source[] = [];
  private nextId: number = 0;
  private renderer: Renderer;
  private spawnTimer: number = 0;
  private frbTimer: number = 0;
  private baseSpawnInterval: number = 2.0; // seconds between spawns
  private frbBaseInterval: number = 15.0;  // seconds between FRB chances

  constructor(renderer: Renderer) {
    this.renderer = renderer;
  }

  update(deltaTime: number, difficultyMultiplier: number): void {
    // Update spawn timers
    this.spawnTimer += deltaTime;
    this.frbTimer += deltaTime;

    // Spawn regular sources
    const spawnInterval = this.baseSpawnInterval / difficultyMultiplier;
    if (this.spawnTimer >= spawnInterval) {
      this.spawnTimer = 0;
      this.spawnRandomSource(difficultyMultiplier);
    }

    // Spawn FRBs occasionally
    const frbInterval = this.frbBaseInterval / Math.sqrt(difficultyMultiplier);
    if (this.frbTimer >= frbInterval) {
      this.frbTimer = 0;
      if (Math.random() < 0.3) { // 30% chance when timer triggers
        this.spawnFRB(difficultyMultiplier);
      }
    }

    // Update all sources
    for (const source of this.sources) {
      source.x -= source.speed * deltaTime * difficultyMultiplier;
      source.age += deltaTime;
    }

    // Remove sources that have left screen or expired
    this.sources = this.sources.filter((source) => {
      // Remove if off screen left
      if (source.x < -50) return false;

      // Remove FRBs after their lifetime
      if (source.type === 'frb' && source.lifetime && source.age >= source.lifetime) {
        return false;
      }

      // Keep if not complete (completed sources are removed elsewhere after scoring)
      return true;
    });
  }

  private spawnRandomSource(difficultyMultiplier: number): void {
    const type = SOURCE_TYPES[Math.floor(Math.random() * SOURCE_TYPES.length)]!;
    this.spawnSource(type, difficultyMultiplier);
  }

  private spawnSource(type: SourceType, difficultyMultiplier: number): void {
    const config = SOURCE_CONFIGS[type];
    const groundY = this.renderer.getGroundY();

    // Spawn in the sky portion (upper 70% of screen before ground)
    const minY = 50;
    const maxY = groundY - 100;
    const y = minY + Math.random() * (maxY - minY);

    const source: Source = {
      id: this.nextId++,
      type,
      x: this.renderer.width + config.size,
      y,
      size: config.size,
      observationTime: config.observationTime,
      observedTime: 0,
      points: config.points,
      speed: config.speed,
      color: config.color,
      lifetime: config.lifetime,
      age: 0,
      isComplete: false,
    };

    this.sources.push(source);
  }

  private spawnFRB(difficultyMultiplier: number): void {
    const config = SOURCE_CONFIGS['frb'];
    const groundY = this.renderer.getGroundY();

    // FRBs can appear anywhere in the sky
    const minY = 80;
    const maxY = groundY - 100;
    const y = minY + Math.random() * (maxY - minY);

    // FRBs appear at random x positions (not just at edge)
    const x = 200 + Math.random() * (this.renderer.width - 400);

    const source: Source = {
      id: this.nextId++,
      type: 'frb',
      x,
      y,
      size: config.size,
      observationTime: config.observationTime,
      observedTime: 0,
      points: config.points,
      speed: 0, // FRBs don't move, they just appear and disappear
      color: config.color,
      lifetime: config.lifetime,
      age: 0,
      isComplete: false,
    };

    this.sources.push(source);
  }

  getSources(): Source[] {
    return this.sources;
  }

  markSourceComplete(id: number): void {
    const source = this.sources.find((s) => s.id === id);
    if (source) {
      source.isComplete = true;
    }
  }

  removeSource(id: number): void {
    this.sources = this.sources.filter((s) => s.id !== id);
  }

  draw(): void {
    for (const source of this.sources) {
      const progress = source.observedTime / source.observationTime;
      drawSource(
        this.renderer,
        source.x,
        source.y,
        source.type,
        source.size,
        progress,
        source.age
      );
    }
  }

  reset(): void {
    this.sources = [];
    this.spawnTimer = 0;
    this.frbTimer = 0;
  }
}

// Beam-object collision detection

import type { BeamState, Source, Satellite } from './types.ts';

// Check if beam overlaps with a source
export function beamIntersectsSource(beam: BeamState, source: Source): boolean {
  const dx = beam.x - source.x;
  const dy = beam.y - source.y;
  const distance = Math.sqrt(dx * dx + dy * dy);

  return distance < beam.radius + source.size;
}

// Check if beam overlaps with a satellite
export function beamIntersectsSatellite(beam: BeamState, satellite: Satellite): boolean {
  const dx = beam.x - satellite.x;
  const dy = beam.y - satellite.y;
  const distance = Math.sqrt(dx * dx + dy * dy);

  // Satellite hitbox is roughly circular
  const satelliteRadius = satellite.size * 0.8;

  return distance < beam.radius + satelliteRadius;
}

// Process all collisions and return observation results
export interface CollisionResult {
  observedSources: { source: Source; deltaObservation: number }[];
  hitSatellites: Satellite[];
  completedSources: Source[];
}

export function processCollisions(
  beam: BeamState,
  sources: Source[],
  satellites: Satellite[],
  deltaTime: number
): CollisionResult {
  const result: CollisionResult = {
    observedSources: [],
    hitSatellites: [],
    completedSources: [],
  };

  // Check sources
  for (const source of sources) {
    if (source.isComplete) continue;

    if (beamIntersectsSource(beam, source)) {
      // Accumulate observation time
      source.observedTime += deltaTime;

      result.observedSources.push({
        source,
        deltaObservation: deltaTime,
      });

      // Check if observation is complete
      if (source.observedTime >= source.observationTime) {
        source.isComplete = true;
        result.completedSources.push(source);
      }
    }
  }

  // Check satellites
  for (const satellite of satellites) {
    if (satellite.wasHit) continue;

    if (beamIntersectsSatellite(beam, satellite)) {
      satellite.wasHit = true;
      result.hitSatellites.push(satellite);
    }
  }

  return result;
}

// Main entry point - game loop and initialization

import { Renderer } from './renderer.ts';
import { Game } from './game.ts';

let game: Game;
let lastTime: number = 0;

function init(): void {
  const renderer = new Renderer('game-canvas');
  game = new Game(renderer);

  // Set up input handlers
  setupInputHandlers(renderer);

  // Start game loop
  lastTime = performance.now();
  requestAnimationFrame(gameLoop);
}

function setupInputHandlers(renderer: Renderer): void {
  // Mouse move
  renderer.canvas.addEventListener('mousemove', (event: MouseEvent) => {
    const pos = renderer.getMousePosition(event);
    game.handleMouseMove(pos.x, pos.y);
  });

  // Click
  renderer.canvas.addEventListener('click', () => {
    game.handleClick();
  });

  // Keyboard
  window.addEventListener('keydown', (event: KeyboardEvent) => {
    game.handleKeyDown(event.key);
  });

  // Prevent context menu on right click
  renderer.canvas.addEventListener('contextmenu', (event: Event) => {
    event.preventDefault();
  });
}

function gameLoop(currentTime: number): void {
  const deltaTime = Math.min((currentTime - lastTime) / 1000, 0.1); // Cap delta to prevent physics issues
  lastTime = currentTime;

  // Update
  game.update(deltaTime);

  // Draw
  game.draw();

  // Continue loop
  requestAnimationFrame(gameLoop);
}

// Initialize when DOM is ready
if (document.readyState === 'loading') {
  document.addEventListener('DOMContentLoaded', init);
} else {
  init();
}

// Development server using Bun's built-in server

const server = Bun.serve({
  port: 3000,
  async fetch(request) {
    const url = new URL(request.url);
    let path = url.pathname;

    // Default to index.html
    if (path === '/') {
      path = '/index.html';
    }

    // Serve files from the project directory
    const filePath = '.' + path;

    try {
      const file = Bun.file(filePath);

      if (await file.exists()) {
        // Determine content type
        let contentType = 'application/octet-stream';
        if (path.endsWith('.html')) contentType = 'text/html';
        else if (path.endsWith('.ts')) contentType = 'application/javascript';
        else if (path.endsWith('.js')) contentType = 'application/javascript';
        else if (path.endsWith('.css')) contentType = 'text/css';
        else if (path.endsWith('.json')) contentType = 'application/json';

        // For TypeScript files, transpile them
        if (path.endsWith('.ts')) {
          const transpiler = new Bun.Transpiler({
            loader: 'ts',
          });
          const code = await file.text();
          const result = transpiler.transformSync(code);
          return new Response(result, {
            headers: { 'Content-Type': 'application/javascript' },
          });
        }

        return new Response(file, {
          headers: { 'Content-Type': contentType },
        });
      }
    } catch (e) {
      // File not found, fall through
    }

    return new Response('Not Found', { status: 404 });
  },
});

console.log(`Server running at http://localhost:${server.port}`);
